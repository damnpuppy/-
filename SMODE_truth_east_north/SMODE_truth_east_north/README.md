# S-MODE ROMS 模拟参考场与 OSSE 模拟真值：正东／正北动图窗口

## 模拟参考场与模拟真值

**模拟参考场**强调数据来源：这是一套由海洋模式计算得到的三维状态，不是实测海洋。**模拟真值**强调实验角色：当本场被指定为某次 OSSE 中虚拟海洋的已知状态，用来生成模拟观测并独立评价重构结果时，它就是该次实验的模拟真值（nature run）。同一套数据可以承担这两个角色。

观测模拟器按传感器的位置、深度、时刻和测量范围从模拟真值生成带误差的观测。重构器和规划器只能读取背景、先验及当时已发布的观测，不能读取完整真值。评价器则在**同一时刻、同一变量定义和同一空间支撑**下比较重构结果与真值。若只拿另一套模式场作旁证，两者的差异不能直接称为重构误差。

## 研究范围

本目录对应 `eddy_evolution_east_north.gif` 的固定绘图区。首帧诊断涡心为坐标原点（235.878703927°E，38.648793597°N），东向范围 −19 至 17 km，北向范围 −33 至 12 km。使用动图相同的经纬度到局部距离换算和固定原点。

原生 ROMS 网格与地理方向不对齐。输出在原生网格上取包围矩形并额外留 3 个原生网格点的缓冲，不进行水平重采样。**只将网格文件中 `analysis_mask=1` 的 40,502 个标量网格点作为矩形研究域**；掩膜外的数据保留作交错速度对齐、差分与边缘插值的支撑，不纳入区域统计，也不是陆地。任意位置的区域判断用 `east_km`、`north_km` 的固定上下界。

## 作为 OSSE 模拟真值使用

- `ocean_time` 为时间基准；覆盖 2013-04-01 00:41:36 至 2013-04-02 23:41:36 UTC，原生输出间隔为 1 小时。插值到更密时间只能提供插值环境，不能补出未保存的分钟级演化。
- `temperature` 是位温；`salinity` 是源文件的盐度；`density` 是密度异常，不能直接当绝对密度。模拟观测时按目标传感器的变量定义和支撑进行转换。
- `u`、`v` 保持原生交错网格。若需要标量网格上的东、北向速度，先在有效点对齐交错分量，再利用 `angle` 旋转。固定米制深度的速度取样还应处理速度面所在位置的垂向坐标。
- 垂向深度从当时海面向下为正，保留海底至海面的原始层序。深度按与 UCLA ROMS 文档一致的变换重建，**尚未与该次运行的归档源码独立核实**；没有将状态变量垂向重采样。
- 将模式场作为 OSSE 的数值参考场，不视为现实海洋的实测真值。完整场仅供观测模拟器和独立评价器读取，不直接交给重构和规划模块。

## 缩写、变量、坐标与单位注释

| 符号、缩写或字段 | 含义与单位 |
|---|---|
| S-MODE | Sub-Mesoscale Ocean Dynamics Experiment，次中尺度海洋动力学实验；这里是数据集名称。 |
| ROMS | Regional Ocean Modeling System，区域海洋模式系统。 |
| OSSE | Observing System Simulation Experiment，观测系统模拟实验。 |
| NetCDF、`.nc` | 本目录用于存放带维度和元数据的科学数组的文件格式及其扩展名。 |
| UTC、°E、°N、km、m | 分别为协调世界时、东经度、北纬度、千米、米。经度采用 0–360° 表示。 |
| `east_km`、`north_km` | 相对于首帧诊断涡心的局部东向、北向距离，单位 km；负值分别表示向西、向南。 |
| `analysis_mask` | 矩形研究域掩膜，1 为框内、0 为框外；无量纲。它不是海陆掩膜。 |
| `lon_rho`、`lat_rho` | 标量网格点的经度、纬度，单位分别为东经度、北纬度。 |
| `mask_rho` | 标量网格海陆掩膜，1 为水点、0 为陆点；无量纲。 |
| `h`、`zeta` | `h` 为参考海面到海底的水深，向下为正；`zeta` 为当时海面相对参考面的高度，向上为正，二者单位均为 m。 |
| `angle`、`pm`、`pn` | `angle` 为从地理正东到原生网格第一轴的旋转角，单位 rad；`pm`、`pn` 分别为原生网格两方向网格间距的倒数，单位 m⁻¹。 |
| `ocean_time` | 原始模式时间，按变量属性 `units` 解码；本批文件采用自 1950-01-01 起的天数。 |
| `temperature`、`salinity`、`density` | 分别为位温（℃）、源文件盐度（单位属性为 1）、密度异常（kg/m³）。 |
| `u`、`v`、`w` | 原生网格两方向的水平流速和垂向流速，单位 m/s。水平分量不直接等同于地理东、北向流速。 |
| `depth_rho`、`depth_w` | 分别为层中心和层界面距当时海面的深度，单位 m，向下为正；`rho`、`w` 在此是网格位置标签。 |
| `layer_thickness` | 每层下界面深度减上界面深度，单位 m。 |
| `s_rho`、`s_w`、`Cs_r`、`Cs_w` | 垂向坐标文件中，前两项为重建的无量纲层中心、层界面坐标，后两项为原文件保存的无量纲垂向拉伸曲线。 |

### 其余状态场与范围字段

- `time_step`：模式积分步和输出记录编号；`ubar`、`vbar`：水柱平均水平流速（m/s），不是海面流速；`Akv`：垂向动量黏性系数（m²/s）；`hbls`、`hbbl`：表层和底部边界层厚度（m）。
- `region.json` 中，`origin_lon_deg_e`、`origin_lat_deg_n` 是原点经纬度；`east_scale_km_per_degree`、`north_scale_km_per_degree` 是经纬度差换算成局部距离的比例（km/度）；`zero_based_native_slice` 按行起点、行终点、列起点、列终点排列，索引从 0 开始，终点不含；`native_rho_shape` 为标量网格行列数；`mask_inside_count` 是框内点数；`support_margin_grid_cells` 是原生包围框额外保留的网格点数；`lon_min_deg_e`、`lon_max_deg_e`、`lat_min_deg_n`、`lat_max_deg_n` 是框内点经纬度的极值。经纬度极值不是原生网格边界。

来源：[NASA S-MODE ROMS 输出](https://doi.org/10.5067/SMODE-ROMS)，[配套网格](https://doi.org/10.5067/SMODE-ROMS-ANC)。
